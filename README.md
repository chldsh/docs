# myBill.Pal docs

Documentation for myBill.Pal, the budgeting web app by Peekardo Collectives. The site is built with [Mintlify](https://mintlify.com).

## Development

Install the [Mintlify CLI](https://www.npmjs.com/package/mint) to preview your documentation changes locally:

```bash
npm i -g mint
```

Run the following command at the root of the repository, where `docs.json` is located:

```bash
mint dev
```

View your local preview at `http://localhost:3000`.

## Publishing changes

Changes deploy to production automatically after they merge into the default branch.
